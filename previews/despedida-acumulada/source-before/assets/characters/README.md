# Personagens da apresentação

Gerados com a ferramenta integrada ImageGen, usando as fotos fornecidas como referência. Os PNGs preservam a transparência. Cada personagem aparece no segundo slide após um clique, junto do cargo e do nome. As animações de entrada e respiração estão em bookends.js e style.css. Os PNGs são usados inteiros, sem máscaras ou movimento isolado das mãos.

Arquivos finais: gustavo.png, eric.png e josi-cacheada.png.
